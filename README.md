# 🛒 Olist E-Commerce Data Analysis

Data analytics project on Olist e-commerce sales, using **Excel, Tableau, Power BI, and SQL** to uncover customer trends, optimize inventory, and visualize business insights.

## 🎯 Overview

This project analyzes the Olist e-commerce dataset to surface actionable business insights — customer behavior patterns, sales trends, and inventory optimization opportunities — using SQL for data querying and BI tools for visualization.

## 🛠️ Tools & Files

| File | Description |
|---|---|
| `olist.sql` | SQL queries used to explore, clean, and analyze the Olist sales dataset |
| `Olist E-Commerce Data Analysis.pptx` | Presentation summarizing the analysis, findings, and business recommendations |

## 🚀 How to View

- **SQL queries:** Open `olist.sql` in any text editor or SQL client to see the analysis logic.
- **Presentation:** Open `Olist E-Commerce Data Analysis.pptx` in PowerPoint or Google Slides for the full write-up and visuals.

## 🔑 Key Skills Demonstrated

- SQL-based data exploration and analysis
- Customer trend and behavior analysis
- Inventory optimization insights
- Business insight presentation & storytelling
